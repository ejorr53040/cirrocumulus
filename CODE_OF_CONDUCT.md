# Code of conduct

Cirrocumulus follows the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), in
every project space: issues, pull requests, discussions and anywhere else
you represent the project.

In short: be kind, assume good faith, welcome newcomers, and take criticism
of code as criticism of code. Harassment of any kind isn't tolerated.

To report a problem, contact the maintainer privately through GitHub
([@ejorr53040](https://github.com/ejorr53040)). Reports are kept
confidential, and handled under the Covenant's enforcement guidelines.
